# TLX-S LINK SDK for COM Docs

Here you will find the code snippets in VBA to document the development of SIMATIC S7 connected applications using our TLX-S LINK SDK for COM (formerly IP S7 LINK SDK for COM). The snippets also run in VB6.

## Code Snippets

The code snippets in this repository are defined as they are and do not (necessarily) implement a whole scenario. Each file is a VBA module that can be imported into the VBA editor (File > Import File). The snippets expect a reference to the type library of the SDK and the module `Helper.bas` from the [samples](https://github.com/Traeger-GmbH/ips7linkcom-samples).

The files are stored with CRLF line endings and in ASCII, as the VBA editor expects them.
